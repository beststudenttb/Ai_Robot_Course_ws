# 我的课程作业

## 机器人 & 仿真 
### 四麦轮底盘 and Webots2023b
本科毕设使用的软件和底盘,还在陪我.也是懒得在建新的

## 系统结构
### 用户层
键盘输入目的地指令(A,B,C),还有个base_mission,按照ABC的顺序在完成当前指令是发送下一个指令
### 感知层
Supervisor获取机器人位姿
### 决策层
监听用户层的指令和感知层的位姿,结算移动指令发布给底盘
### 底盘
监听决策层的指令,然后逆解四轮速度.

这个任务是本科期间参加的中国高校智能机器人创意大赛主题三无人机A赛项demo的究极简化版.
无人机->四轮底盘,imu+px4+lidar->supervisor.
